밥돌이 조작부 사용 설명서

기본 사용법과 메뉴(시간·화력) 설정 변경 방법입니다. 시뮬레이터로 돌아가기

1. 키 이름

키하는 일
1 2 3 4메뉴 선택. 선택한 메뉴의 표시등이 켜집니다.
▲ ▼설정 변경 중에 값을 올리고 내립니다.
START/STOP취반 시작, 일시정지, 다시 시작.
전원전원을 켜고 끕니다.

숫자 표시창 아래의 1단계~4단계 표시등은 메뉴의 단계입니다. 취반 중에는 지금 진행하는 단계가 켜집니다.

2. 기본 사용법

  1. 전원을 짧게 누릅니다. 표시창에 선택된 메뉴의 총 시간이 나옵니다.
  2. 메뉴 1~4 중 쓸 메뉴를 누릅니다. 표시등이 켜진 메뉴가 선택된 메뉴입니다.
  3. 솥을 올리고 START/STOP을 짧게 누르면 취반이 시작됩니다. 1단계부터 차례로 진행합니다.
  4. 취반이 끝나면 알림음이 3번 울립니다. 그대로 두면 1분, 2분 뒤에 한 번씩 더 알려 줍니다.
  5. 끝난 뒤 START/STOP을 누르면 대기 상태로 돌아가고, 한 번 더 누르면 같은 메뉴로 다시 시작합니다.

3. 취반 중에 할 수 있는 일

하고 싶은 일방법
잠시 멈추기취반 중 START/STOP을 짧게 누릅니다. 멈춰 있는 동안 30초마다 알림음이 울립니다.
다시 시작멈춘 상태에서 START/STOP을 짧게 누릅니다.
취반 취소멈춘 상태에서 START/STOP을 2초 누릅니다. 멈춘 채 10분이 지나면 자동으로 취소됩니다.
다른 메뉴로 바꾸기멈춘 상태나 완료 상태에서 다른 메뉴 키를 누르면 그 메뉴가 선택되고 대기 상태가 됩니다.
전원 끄기취반 중이거나 멈춘 상태에서는 전원을 2초 누릅니다. 대기나 완료 상태에서는 짧게 누르면 됩니다.

솥을 빼면 취반 중에 E0이 표시됩니다. 1분 안에 솥을 다시 올리면 이어서 취반하고, 1분이 지나면 취소됩니다. 대기나 완료 상태로 10분 동안 아무것도 누르지 않으면 전원이 꺼집니다.

4. 설정 변경 (메뉴의 시간과 화력 바꾸기)

각 메뉴(1~4)는 4단계까지 시간과 화력을 정할 수 있습니다. 대기 상태에서 바꿉니다.

  1. 바꿀 메뉴 키를 2초 누릅니다. 설정 변경 모드가 되고 1단계의 시간부터 보여 줍니다.
  2. ▲ ▼로 값을 바꿉니다.
    • 시간: 한 번 누를 때마다 10초씩 바뀝니다. 길게 누르면 1분씩 바뀝니다. 최대 20:00입니다.
    • 화력: 한 번에 1씩 바뀝니다. 1~10이고, 2단계부터는 0도 쓸 수 있습니다.
  3. 같은 메뉴 키를 짧게 누르면 다음 항목으로 넘어갑니다. 순서는 1단계 시간 → 1단계 화력 → 2단계 시간 → … → 4단계 화력이고, 마지막 뒤에는 처음으로 돌아갑니다.
  4. START/STOP을 누르면 저장하고 대기 상태로 돌아갑니다.

저장하지 않고 나가려면 전원을 누릅니다. 30초 동안 아무것도 누르지 않아도 저장하지 않고 나갑니다. 설정 변경 중에는 다른 메뉴 키가 반응하지 않습니다.

5. 단계를 정하는 규칙

  • 1단계는 시간이 10초 이상, 화력이 1 이상이어야 합니다.
  • 시간을 0으로 하면 그 단계에서 레시피가 끝납니다. 그 뒤 단계는 "----"로 표시되고 값을 바꿀 수 없으며, 저장하면 0으로 저장됩니다.
  • 화력을 0으로 하고 시간을 넣으면 불을 끄고 기다리는 단계(뜸 들이기)가 됩니다. 그 뒤 단계에서 다시 가열하는 레시피도 만들 수 있습니다.

6. 출고 레시피로 되돌리기

  1. 전원을 끈 상태에서 START/STOP을 5초 누릅니다. 표시창에 rSt가 깜박입니다.
  2. 5초 안에 START/STOP을 한 번 더 누르면 복원됩니다. 다른 키를 누르거나 5초가 지나면 취소됩니다.

출고 값은 모든 메뉴가 1단계 7:00 / 화력 7, 2단계 3:00 / 화력 7, 3·4단계 0입니다.
